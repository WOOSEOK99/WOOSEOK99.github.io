EKLAUNCHER · MOBILE GUIDE

EKLauncher
사용설명서

휴대폰에서 보기 편한 설명서입니다. 게임 시작, 터치 조작, 외장 게임패드 설정부터 문제 해결까지 순서대로 안내합니다.

게임 시작터치 조작외장 게임패드문제 해결

처음 사용할 때

  1. 앱 메인 화면과 게임 목록을 확인하세요.
  2. 설정 → ROM → 디렉토리에서 게임 파일 폴더를 지정하세요.
  3. 게임을 실행하고 게임 메뉴로 이동하여 저장과 조작 방법을 확인하세요.
  4. 입력 문제가 있으면 터치 입력 방식 항목을 참고하세요.

원하는 항목을 눌러 이동하세요.

CHAPTER 01

01. 시작하기

Getting started

게임을 찾고 ROM 폴더를 설정하는 기본 흐름

처음 실행한 다음에는 게임 목록을 확인하고, 필요한 경우 ROM 저장 위치를 지정하세요.

01 / FIELD GUIDE

앱 첫 화면

Home screen

앱을 실행하면 보이는 메인 화면입니다.

사용 방법 시스템 분류, 게임 목록, 설정으로 이동할 수 있는 항목을 확인합니다.

참고 설치된 앱 버전에 따라 배치가 다를 수 있습니다.

02 / FIELD GUIDE

게임 목록

Game library

시스템별 게임 목록에서 실행할 게임을 선택합니다.

사용 방법 목록에서 게임을 눌러 실행합니다. 게임이 안 보이면 ROM 폴더와 검색 상태를 확인하세요.

참고 화면에 개인적인 파일 경로가 나타나면 가려주세요.

03 / FIELD GUIDE

설정 화면

Main settings

메인 화면에서 설정을 열면 ROM, 일반, 입력, 기타 항목을 확인할 수 있습니다.

사용 방법 ROM 디렉토리, 상태 자동 저장, 화면 표시, 외장 장치, 고급 설정 등이 구분되어 있습니다.

참고 화면을 위아래로 스크롤해야 모든 설정이 보일 수 있습니다.

04 / FIELD GUIDE

ROM 폴더 지정

ROM directory

설정 → ROM → 디렉토리에서 게임 파일을 보관한 폴더를 선택합니다.

사용 방법 Android 폴더 선택 화면에서 저장 위치를 찾아 선택하고 접근 권한을 승인합니다.

참고 폴더 이름과 경로에 개인정보가 포함되어 있지 않은지 확인하세요.

05 / FIELD GUIDE

게임 검색

Search games

게임 검색 화면에서 제목으로 게임을 찾습니다.

사용 방법 목록에서 찾기 어려울 때 검색 기능을 활용하세요.

참고 선택적으로 나중에 촬영해도 됩니다.

06 / FIELD GUIDE

즐겨찾기

Favorites

즐겨찾기 목록이 표시되는 화면입니다.

사용 방법 자주 실행하는 게임을 모아 빠르게 접근할 때 사용합니다.

참고 즐겨찾기 등록 방식은 실제 앱 메뉴를 기준으로 확인하세요.

CHAPTER 02

02. 게임 실행과 게임 메뉴

Playing and in-game menu

저장·불러오기와 게임별 옵션 사용 방법

게임 실행 중 호출하는 게임 메뉴에는 저장, 불러오기, 다시 시작, 컨트롤 변경 등의 기능이 있습니다.

07 / FIELD GUIDE

게임 실행 화면

Gameplay

가상 컨트롤러가 나타난 실제 게임 실행 화면입니다.

사용 방법 화면의 방향 버튼과 액션 버튼을 눌러 조작합니다. 외장 게임패드가 연결되어 있다면 해당 입력도 사용할 수 있습니다.

참고 게임 제목이나 라이선스 문제가 생길 수 있는 콘텐츠 대신 직접 보유한 화면을 사용하세요.

08 / FIELD GUIDE

게임 메뉴 호출

In-game menu

게임 플레이 도중 게임 메뉴를 연 상태입니다.

사용 방법 메뉴에서 저장, 불러오기, 다시 시작, 종료, 음소거, 빨리 감기, 컨트롤 변경, 게임별 설정 등 제공되는 항목을 선택할 수 있습니다.

참고 게임 종류나 지원 기능에 따라 일부 메뉴가 표시되지 않을 수 있습니다.

09 / FIELD GUIDE

상태 저장과 불러오기

Save and load states

게임 메뉴의 저장 또는 불러오기 화면입니다.

사용 방법 저장할 슬롯을 선택하거나 기존 저장 상태를 불러옵니다. 중요한 진행 상황은 게임 자체의 저장 기능도 함께 사용하세요.

참고 상태 파일은 사용 중인 코어와 게임 상태에 영향을 받을 수 있습니다.

10 / FIELD GUIDE

게임별 설정

Game options

게임 메뉴의 설정(코어 옵션) 화면입니다.

사용 방법 게임별 옵션을 변경할 때 사용합니다. 항목은 실행 중인 게임 및 코어에 따라 달라집니다.

참고 정확한 옵션명은 해당 코어에 표시되는 값을 우선하세요.

11 / FIELD GUIDE

게임 삭제

Removing a game

게임 목록에서 삭제 메뉴나 삭제 확인 창을 표시합니다.

사용 방법 삭제 전에는 화면에 표시되는 삭제 대상과 영향 범위를 반드시 확인하세요.

참고 촬영할 때는 최종 삭제 버튼을 누를 필요가 없습니다.

CHAPTER 03

03. 가상 컨트롤러 설정

On-screen controls

간격·크기·편집·매크로·버튼 수 조절

실행 중인 게임의 게임 메뉴에서 컨트롤 변경을 선택하여 화면 컨트롤을 조정합니다. 일부 설정은 게임별로 저장됩니다.

12 / FIELD GUIDE

컨트롤 변경 시작

Control customization

게임 메뉴 → 컨트롤 변경으로 이동한 첫 화면입니다.

사용 방법 간격조절·옵션·편집 탭을 살펴보고, 바꾸려는 종류를 선택합니다.

참고 게임 중 메뉴에서 진입한 화면을 찍어 주세요.

13 / FIELD GUIDE

버튼 간격 조절

Spacing

가로 배치 간격과 세로 배치 간격을 조절하는 화면입니다.

사용 방법 실제 게임 화면을 보면서 컨트롤끼리 겹치지 않도록 간격을 변경합니다.

참고 기기를 세로와 가로로 돌려 사용하는 경우 각각 배치를 확인하세요.

14 / FIELD GUIDE

컨트롤 옵션

Control options

버튼 크기 등 세부 설정이 나오는 옵션 탭입니다.

사용 방법 전체 크기, 회전 및 화면에 제공되는 추가 옵션을 조정합니다.

참고 버전마다 노출 항목이 다를 수 있으므로 표시된 옵션만 설명합니다.

15 / FIELD GUIDE

편집 모드

Edit mode

편집 모드를 켜고 버튼 위치나 크기를 바꾸는 화면입니다.

사용 방법 편집 모드를 활성화한 후 화면의 버튼을 선택하여 위치·크기를 조정합니다.

참고 편집 중에는 기존 게임 조작과 다른 방식으로 터치가 처리될 수 있습니다.

16 / FIELD GUIDE

개별 버튼 수정

Edit button

수정할 버튼의 상세 옵션이나 길게 누른 후 편집 화면입니다.

사용 방법 버튼 텍스트, 크기, 매핑 가능한 동작 등 보이는 옵션을 수정합니다.

참고 실제 화면에 없는 세부 기능은 사용하지 않는 것이 좋습니다.

17 / FIELD GUIDE

매크로 조합 선택

Macro combo

버튼 하나에 여러 입력을 조합하는 매크로 설정 화면입니다.

사용 방법 매크로 조합 선택에서 함께 활성화할 버튼을 골라 구성합니다.

참고 게임마다 지원하는 조작 조합이 다를 수 있습니다.

18 / FIELD GUIDE

버튼 개수 변경

Button count

버튼 개수 변경이나 디폴트 선택 화면입니다.

사용 방법 게임에 맞는 버튼 구성을 선택하고 필요하면 기본값으로 되돌립니다.

참고 수정 뒤에는 저장 후 닫기 동작을 확인하세요.

CHAPTER 04

04. 외장 게임패드와 버튼 매핑

Gamepads and mappings

1P/2P, 할당 해제, 단축키, 아케이드 버튼 재할당

설정 → 입력 → 외장 장치에서 연결된 컨트롤러를 관리하고 키를 배정합니다.

19 / FIELD GUIDE

외장 장치 목록

External controllers

설정 → 외장 장치를 연 화면입니다.

사용 방법 연결된 게임패드와 키보드 등을 확인하고 필요한 장치를 활성화합니다.

참고 장치가 목록에 없으면 Android 측 연결 상태부터 확인하세요.

20 / FIELD GUIDE

1P / 2P 키 매핑

Player mappings

플레이어 구분이 표시된 키 매핑 항목을 촬영합니다.

사용 방법 1P와 2P를 확인한 뒤 수정할 RetroPad 항목을 선택합니다.

참고 동일한 모델의 패드가 둘 이상 있으면 장치별 동작을 확인하세요.

21 / FIELD GUIDE

키 할당과 할당 해제

Bind / unbind

개별 키 배정 시 나타나는 팝업에서 할당 해제 버튼이 보이게 촬영합니다.

사용 방법 잘못 입력되는 버튼을 해제하면 해당 물리 키 배정을 없앨 수 있습니다.

참고 원래 입력을 복원하려면 다시 키를 배정하거나 매핑 초기화를 사용하세요.

22 / FIELD GUIDE

가상 버튼 조합

Virtual shortcuts

Virtual L3/R3/L2/R2 등 단축키 설정이 보이는 화면입니다.

사용 방법 물리 버튼이 부족한 경우 두 버튼의 조합으로 지정한 동작을 호출하도록 설정합니다.

참고 사용 중인 게임의 실제 조작과 충돌하지 않는 조합을 선택하세요.

23 / FIELD GUIDE

아케이드 버튼 재할당

Arcade button remapping

설정 → 버튼 재할당에서 2·4·6버튼 프로필이나 실제 재할당 화면을 촬영합니다.

사용 방법 아케이드 게임의 버튼 구성에 맞춰 화면 버튼과 실제 입력의 대응을 조절할 수 있습니다.

참고 게임별 컨트롤 설정에는 별도 재할당 항목이 있을 수 있습니다.

CHAPTER 05

05. 고급 설정과 문제 해결

Advanced settings and troubleshooting

터치 입력 엔진, 스틱, 오동작 방지, 진단

설정 → 고급 설정에서는 터치 조작 방식과 호환성 관련 항목을 조절할 수 있습니다.

24 / FIELD GUIDE

고급 설정 화면

Advanced settings

설정 → 고급 설정으로 들어간 화면입니다.

사용 방법 입력, 터치 스틱 방식, 오동작 방지, 개발자 진단, 일반 설정의 위치를 확인합니다.

참고 스크롤 화면이 길면 주요 항목이 나오는 위치에서 촬영하세요.

25 / FIELD GUIDE

터치 입력 방식 선택

Touch input engine

터치 입력 방식 선택창에서 기본 입력 방식(PadKit)과 호환성 입력 방식(Android Native)이 모두 보이게 촬영합니다.

사용 방법 동시 터치, 특정 버튼 반응 문제 등이 있을 때 호환성 입력 방식을 선택하여 비교해 볼 수 있습니다.

참고 선택한 입력 방식은 다음 게임 실행부터 적용됩니다. 이미 실행 중인 게임에서는 바뀌지 않습니다.

26 / FIELD GUIDE

터치 스틱 방식과 데드존

Touch stick and deadzone

십자 버튼과 둥근 스틱 선택 카드, 데드존 조절 항목이 보이는 화면입니다.

사용 방법 십자 스틱과 둥근 스틱 중 선호 방식으로 설정하고, 오입력이나 반응이 늦다면 해당 임계값을 조절합니다.

참고 기종과 게임에 따라 적합한 설정이 다르므로 작은 단위로 조절해 비교하세요.

27 / FIELD GUIDE

오동작 방지

Edge touch protection

오동작 방지 기능 활성화, 가로·세로 여백 설정 화면입니다.

사용 방법 휴대폰 화면 가장자리에서 원치 않는 터치가 발생하면 여백 값을 조절합니다.

참고 여백을 지나치게 늘리면 조작 가능한 영역이 좁아질 수 있습니다.

28 / FIELD GUIDE

컨트롤러 진단 로그

Input diagnostics

진단 로그 기록 및 공유 항목을 보여 주는 화면입니다.

사용 방법 문제 재현 전에 기록을 켜고, 게임을 종료한 후 공유 메뉴를 사용하여 로그를 전달할 수 있습니다.

참고 진단 로그에 개인 정보가 포함되어 있지 않은지 확인하고 공유하세요.

29 / FIELD GUIDE

BIOS 인식 상태

BIOS status

설정 → BIOS 화면입니다.

사용 방법 인식된 BIOS와 인식되지 않은 BIOS 항목을 확인할 수 있습니다.

참고 필요한 BIOS 종류는 게임 및 코어마다 다릅니다.

30 / FIELD GUIDE

화면과 일반 설정

Display and general

일반 설정에서 화면 꽉 채우기, HD 모드, 필터, 자동 저장 등 항목이 보이게 촬영합니다.

사용 방법 게임 화면 비율, 화질 후처리, 상태 자동 저장 등의 옵션을 필요에 맞게 선택하세요.

참고 화면 꽉 채우기는 게임의 원래 종횡비를 변경할 수 있습니다.

자주 묻는 질문

A 또는 B 버튼이 버벅거리거나 동시 터치가 잘되지 않습니다.

설정 → 고급 설정 → 터치 입력 방식에서 호환성 입력 방식(Android Native)을 선택한 후 게임을 완전히 종료하고 다시 실행하여 비교하세요. 입력 방식은 다음 게임 실행부터 적용됩니다. 증상이 지속되면 기종, Android 버전, 사용한 게임과 재현 방법을 함께 기록하는 것이 좋습니다.

외장 게임패드의 특정 버튼이 오작동합니다.
